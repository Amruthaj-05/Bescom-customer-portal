# BESCOM Customer Portal

## 📌 Project Overview
The BESCOM Customer Portal is a web-based application developed using Flask that allows electricity board officers to manage customer records efficiently.

## 🚀 Features
- Add new customers
- Update customer details
- Search customer information
- Delete customer records
- User-friendly interface

## 🛠 Technologies Used
- Python (Flask Framework)
- SQLite Database
- HTML, CSS (Frontend)

## 📂 Project Structure
- app.py → Main application file
- database/schema.sql → Database schema
- templates/ → HTML pages
- static/ → CSS and images

## ⚙️ Installation

1. Clone the repository:
   git clone https://github.com/your-username/bescom-portal.git

2. Navigate to project folder:
   cd bescom-portal

3. Install dependencies:
   pip install flask

4. Run the application:
   python app.py

5. Open browser:
   http://127.0.0.1:5000/

## 🗄 Database
SQLite is used as the database.
Schema is available in:
database/schema.sql
